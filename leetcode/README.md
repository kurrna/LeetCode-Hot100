# LeetCode Plugin Workflow (C++)

This folder is for files generated by the VS Code LeetCode extension.

## Structure

- `problems/`: question files generated by `LeetCode: Show Problem`.

## Recommended workflow

1. Open a problem in VS Code LeetCode panel.
2. Run `LeetCode: Show Problem` to generate a local file.
3. Solve inside `// @lc code=start` and `// @lc code=end`.
4. Run `LeetCode: Test Solution`.
5. Run `LeetCode: Submit Solution`.

## Notes

- Do not remove header comments like `@lc app=leetcode.cn id=... lang=cpp`.
- Submission uses the active editor file.
